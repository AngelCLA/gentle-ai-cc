Objective: replace the Bash/Python wrapper with a standalone Go executable while preserving companion separation and existing safety contracts.

Update release/install artifact selection and documentation for native wrapper executables, retain checksums and existing preservation/rollback guarantees. Native Windows fixtures plus six-target cross-compilation provide bounded evidence; cross-compilation is not Unix runtime certification.
